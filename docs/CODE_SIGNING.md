# Code signing policy

## Статус

Corelight подал заявку в SignPath Foundation. Она находится на рассмотрении. Текущие публичные сборки Corelight распространяются без подписи издателя.

## Ответственность и выпуск

- Владелец репозитория [Shtarkerr](https://github.com/Shtarkerr) поддерживает исходный код и сценарии сборки Corelight, проверяет изменения и вручную утверждает запросы на подпись релизов.
- Для подписи используются сборки из публичного репозитория Corelight. GitHub Actions собирает и тестирует приложение на Windows и сохраняет Setup и Portable с привязкой к ревизии исходников.
- При подключении подписи выпуск с подписанными файлами будет содержать ссылку на эту политику. Перед запросом подписи проверяются ревизия, результаты тестов и состав пакетов. Для доступа к GitHub и SignPath требуется многофакторная аутентификация.

## Данные пользователей

Corelight хранит журналы и историю отката на компьютере пользователя. Проект не получает их автоматически. При проверке доступности или восстановлении приложений Corelight обращается к Microsoft Store через WinGet. При восстановлении OneDrive используется установщик Microsoft. На эти операции распространяются условия обработки данных Microsoft. [Политика конфиденциальности Microsoft](https://privacy.microsoft.com/privacystatement)
