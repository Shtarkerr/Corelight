# Corelight

**Оптимизатор Windows 11 для игрового ПК, рассчитанный на пользователей в России.** Помогает выбрать системные настройки, сократить ненужную фоновую активность, убрать приложения и управлять автозагрузкой.

## Что умеет программа

- Сканировать систему и показывать рекомендации с описанием последствий.
- Менять настройки приватности, фоновой активности, служб, сети и игровых функций Windows.
- Удалять выбранные предустановленные приложения, клиент OneDrive и настольный Copilot.
- Включать и отключать программы в автозагрузке.
- Анализировать и очищать временные файлы Windows, выбранные кэши, неработающие ярлыки, пустые папки, «Загрузки» и корзину.
- Сохранять исходные значения настроек и показывать историю изменений.
- Откатывать доступные изменения, открывать страницы Store и инструкции ручного возврата приложений.

Corelight не разгоняет оборудование, не устанавливает драйверы, не меняет файлы игр, Defender, Secure Boot, TPM или службы античитов. Анимации и прозрачность Windows сохраняются. Центр обновления Windows продолжает работать; можно отключить только раздачу обновлений другим компьютерам.

**Прирост FPS пока не измерен.** Результат зависит от исходного состояния Windows, оборудования и игры. Совместимость со всеми античитами не проверялась.

## Требования и получение программы

- Windows 11, 64-разрядная версия x64.
- Права администратора для запуска.
- Интернет и WinGet (компонент «Установщик приложений») для проверки доступности и автоматического возврата приложений из Microsoft Store. Сканирование работает без интернета.

На странице [бета-релиза 0.1.0-beta.6](https://github.com/Shtarkerr/Corelight/releases/tag/v0.1.0-beta.6) выберите файл в разделе **Assets**:

- **Corelight-0.1.0-beta.6-Setup-win-x64.exe** — установщик. Следуйте подсказкам и запускайте программу через ярлык в меню «Пуск». Ярлык на рабочем столе можно выбрать при установке.
- **Corelight-0.1.0-beta.6-Portable-win-x64.exe** — переносной вариант. Запустите скачанный файл.

Обе сборки включают .NET. Бета-выпуски помечены **Pre-release**, контрольные суммы SHA-256 указаны в описании релиза. Архивы **Source code** содержат исходники для разработчиков.

Установщик размещает программу и лицензии в Program Files. Чтобы обновиться, закройте Corelight и запустите новый установщик поверх текущей версии. История и резервные копии сохраняются в **%ProgramData%\Corelight** при обновлении и удалении программы. Чтобы откатить изменения после удаления Corelight, переустановите программу и откройте «История и откат».

## Первый запуск

1. Сохраните открытые документы.
2. Запустите Corelight через ярлык или откройте переносной EXE. Подтвердите запрос прав администратора Windows.
3. Откроется страница **«Главная»** со сведениями о процессоре, видеокарте, памяти и Windows.
4. Нажмите **«Сканировать систему»**.

Сканирование только читает настройки. Если наличие устройства не удалось определить, Corelight учитывает это при выборе рекомендаций.
Если Windows не вернула данные для части проверок, в «Результатах» появится раскрывающийся список с названиями и причинами.

Сборка пока не имеет цифровой подписи. «Интеллектуальное управление приложениями» Windows может заблокировать запуск. Скачивайте файлы со страницы релиза и сверяйте контрольную сумму SHA-256, указанную в его описании.

## Как выбрать рекомендации

На странице **«Результаты сканирования»** (вкладка **«Результаты»**) прочитайте описание каждого пункта и пояснения под ним.

Все пункты в разделе **«Рекомендуемые настройки»** отмечены заранее. Раздел **«Для ручной настройки»** свёрнут. Раскройте его, чтобы прочитать описания и выбрать дополнительные пункты. Галочки в этом списке изначально сняты.

Основной список отсортирован по предполагаемому эффекту. Высокий эффект отмечен фиолетовой плашкой, средний — синей. В «Расширенном» тот же порядок действует внутри каждой категории.

| Отметка | Что означает |
| --- | --- |
| **Безопасно** | Не предполагается отключение заметной пользовательской функции. Всё равно проверьте, нужно ли вам изменение. |
| **Осторожно** | Может отключить используемую функцию или удалить нужное приложение. |
| **Для опытных** | Требуется понимание последствий. По умолчанию такие пункты не выбираются. |
| **Нужна перезагрузка** | Часть результата будет видна после перезагрузки Windows. |
| **Эффект** | Оценка предполагаемого влияния; это не измеренный прирост FPS. |

Галочки по умолчанию заданы для каждого пункта. Среди заранее отмеченных действий есть удаление **Outlook, Teams и Copilot**, отключение **Game DVR** и **родительского контроля**. Прочитайте предупреждения и снимите галочки с функций и приложений, которые хотите сохранить.

**OneDrive, Solitaire, HAGS и отключение отчётов об ошибках Windows** находятся в списке для ручной настройки. «Выбрать рекомендуемые» отмечает пункты основного списка. Число выбранных в ручном списке видно даже когда раздел свёрнут.

При автоматическом обновлении результатов Corelight сохраняет ваш выбор для оставшихся пунктов. Пункт, который снова стал доступен после отката, можно отметить вручную. Новое сканирование на главной возвращает галочки к исходному выбору.

Уже применённые или недоступные настройки не предлагаются повторно. Отсутствие рекомендаций само по себе не означает, что проверены все возможные настройки Windows.

## Как применить изменения

1. Нажмите **«Применить выбранное»**.
2. Проверьте количество пунктов и подтвердите.
3. Перед удалением Corelight покажет выбранные приложения, для которых нужен ручной возврат или установка через Microsoft Store не подтверждена. Нажмите «Пропустить», чтобы сохранить весь показанный список, либо подтвердите удаление.
4. Corelight попробует создать точку восстановления с учётом штатной частоты Windows. Если защита системы отключена, программа предложит включить её. При отсутствии подтверждения новой точки можно продолжить без неё или отменить операцию.
5. Дождитесь отчёта.

Проверка возврата читает каталог Microsoft Store. Найденная запись не гарантирует, что приложение удастся установить позже. Проверку можно остановить до начала изменений.

Если точка не создана, **«Отмена» позволяет остановиться до применения**. Продолжение без точки не заменяет полноценную резервную копию Windows. Записи Corelight сохраняют исходные параметры, но возврат удалённых приложений зависит от наличия установщиков и доступа к сервисам Microsoft.

В отчёте отдельно показаны применённые и частично применённые настройки, ошибки и неподтверждённые результаты. Уже настроенные или недоступные пункты не увеличивают число изменений. При ошибке прочитайте сообщение и проверьте **«Историю и откат»** перед повторной попыткой.

Corelight ждёт ответа Windows до трёх минут на отдельную операцию удаления пакета AppX. По истечении этого времени программа запросит отмену и сохранит запись в истории. Если операция осталась незавершённой после тайм-аута или принудительного закрытия Corelight, выберите **«Перезагрузка»** в меню Windows. После перезагрузки снова откройте **«Историю и откат»** и повторите проверку возврата или откат. При первом обращении к старой незавершённой записи программа может сохранить отметку о текущей загрузке и попросить перезагрузить Windows.

Если Corelight попросил перезагрузить Windows, сначала сохраните свою работу.

После входа проверьте «Пуск», поиск, «Параметры», интернет и используемые приложения.

Для некоторых приложений нужен ручной возврат. Это указано в предупреждениях перед удалением. Например, Teams и настольный Copilot выбираются заранее, а возвращать их нужно вручную.

## Раздел «Расширенное»

В блоке **«Неприменённые настройки»** собраны доступные для этого ПК изменения. Чтобы выполнить одно из них, нажмите **«Применить»** или **«Удалить»** у нужной карточки. Категории помогают найти пункт.

- **Приложения** — установленные приложения из каталога.
- **Телеметрия и приватность** — диагностические данные, реклама и связанные фоновые задачи.
- **Интерфейс и фон** — рекомендации и фоновая работа приложений.
- **Игровые** — игровой режим, запись игр и другие штатные настройки Windows.
- **Службы** — отключение выбранных необязательных служб.
- **Сеть** — отдельные сетевые настройки; DNS и hosts-файл не меняются.

При открытии «Расширенного» Corelight перечитывает состояние системы. Подтверждённые изменения исчезают из списка. Отменить их можно в **«Истории и откате»**. После отката пункт снова появляется, если его можно применить. Для смены схемы питания, ранее применённой Corelight, сначала откатите её в истории.

Если Windows оставила службу работающей, Corelight попросит перезагрузку. При откате по новому снимку программа возвращает тип запуска и пытается восстановить прежнее рабочее состояние службы. При ошибке запись остаётся в истории. Старые снимки содержат только тип запуска.

Corelight предлагает удалить поддерживаемое приложение Microsoft Store, если оно установлено в текущей учётной записи и Windows вернула полный список пакетов. **Удаление затрагивает всех пользователей ПК и предустановку для новых профилей.** При возврате Corelight проверяет установку в текущей учётной записи и сохранённую предустановку по отдельности. Старые записи могут содержать сведения только о наличии приложения. Установка в других существующих профилях выполняется отдельно.

**Copilot (настольная версия)** удаляется штатным деинсталлятором Microsoft. Для ручного возврата используйте «Как вернуть» в истории.

Блок **«Автозагрузка»** управляет запуском программ при входе в Windows. Вернуть автозапуск можно тем же переключателем. Если часть источников недоступна, Corelight покажет те записи, которые удалось прочитать. В списке пока нет автозапуска через задачи планировщика.

## Очистка диска

1. Откройте **«Очистка диска»** в верхнем меню и нажмите **«Анализировать»** внизу справа. На этом этапе файлы сохраняются.
2. После анализа все карточки и найденные файлы отмечены. Откройте нужную карточку, чтобы прочитать описание и проверить список. Файлы идут от большего к меньшему. Снимите галочки с того, что хотите сохранить. Кнопка **«Выбрать все»** снова отмечает все карточки и файлы. Пустые папки отмечаются по одной, корзина выбирается целиком.
3. На месте кнопки анализа появится кнопка с объёмом выбранных данных, например **«Очистить 485 МБ»**. Нажмите её и подтвердите безвозвратное удаление. Кнопка **«Остановить»** завершает обработку после текущего элемента.
4. Итог показывает объём удалённых данных и количество пропущенных элементов. Для следующей очистки нужен новый анализ. Результаты анализа действуют 30 минут.

| Категория | Что очищается |
| --- | --- |
| Временные файлы пользователя и Windows | Файлы старше 7 дней в штатных временных папках |
| Кэш эскизов | Файлы thumbcache старше суток. Миниатюры создадутся заново |
| Кэш шейдеров DirectX | D3DSCache старше суток. Первые запуски игр могут замедлиться |
| Отчёты об ошибках и дампы | Диагностические файлы старше 7 дней |
| Неработающие ярлыки и пустые папки | Ярлыки старше суток с отсутствующей локальной целью в штатных папках рабочего стола и меню «Пуск». Пустые папки любого возраста на первом уровне штатных папок «Рабочий стол» и «Документы» |
| Загрузки | Файлы любого возраста из папки «Загрузки» текущего пользователя, включая вложенные папки |
| Корзина | Всё содержимое корзины текущей учётной записи на всех дисках, включая новые элементы |

Занятые, изменившиеся после анализа, защищённые и облачные файлы пропускаются. Папки-ссылки и жёсткие ссылки обходятся стороной. Для ярлыков недоступный сетевой или съёмный диск, виртуальная цель и ошибка доступа не означают отсутствующую программу.

Область поиска пустых папок ограничена первым уровнем стандартных папок «Рабочий стол» и «Документы» в профиле Windows. Корни дисков и перенаправленные папки исключены. Corelight пропускает системные и скрытые каталоги, папки-ссылки и известные расположения Windows и приложений. Перед удалением Corelight повторно проверяет папку. Папки со скрытыми файлами или дополнительными потоками данных сохраняются.

**Очистка необратима:** раздел «История и откат» и точка восстановления не возвращают удалённые файлы. Содержимое корзины видно справа. Галочка на карточке выбирает корзину целиком. Объём корзины в результате приблизительный. Для остальных категорий объём считается по успешно удалённым файлам.

В «Загрузках» могут быть нужные документы и установщики. Снимите галочки с нужных файлов или со всей категории перед подтверждением. Очистка пропускает сетевые папки, корни дисков и «Загрузки», пересекающиеся с защищёнными расположениями или известной папкой синхронизации OneDrive. В строке «Найдено» корзина учитывается отдельно.

Папка «Документы», профили браузеров и компоненты обновления Windows сохраняются. При запуске от другого администратора пользовательские папки и корзина относятся к его учётной записи. Обработка папок пользователей других профилей не выполняется.

## OneDrive: что важно до удаления

OneDrive синхронизирует файлы с облаком и может хранить рабочий стол, документы и изображения. Отключение его автозапуска и удаление клиента — разные действия.

Перед удалением:

1. Убедитесь, что не используете синхронизацию на этом ПК.
2. Скачайте нужные облачные файлы на компьютер.
3. Если рабочий стол, документы или изображения перенаправлены в OneDrive, отключите их резервное копирование в настройках OneDrive и проверьте расположение локальных файлов.

Corelight блокирует удаление, если обнаруживает такое перенаправление важных папок. Программа не очищает папку OneDrive и не удаляет ваши документы.

Перед удалением сохраняется штатный установщик с проверкой подписи Microsoft. При возврате он используется для того же варианта установки: текущему пользователю или всем пользователям. Если установщик отсутствует или подпись не проходит проверку, операция останавливается с сообщением.

После возврата могут потребоваться интернет и повторный вход в аккаунт. Сохранённый установщик возвращает клиент OneDrive. Облачные файлы и настройки учётной записи в нём не хранятся.

## Как откатить изменения

Откройте **«История и откат»**. Вверху указаны:

- общее число записей;
- число пунктов, доступных для автоматического отката;
- число пунктов с ручным возвратом.

**Для одного пункта:** нажмите рядом **«Откатить»**.

**Для группы:** нажмите **«Откатить доступное»**, прочитайте список и подтвердите. В окне заранее перечислены пункты, которые не входят в автоматический откат.

Успешно возвращённые пункты исчезают из истории. Для новых записей Corelight сохраняет исходное состояние только тех параметров, которые начал менять. При неполном откате история сохраняет оставшиеся действия. Если пункт убрали из каталога или изменили его состав, сохраните файл бэкапа и используйте ту версию Corelight, которой применили настройку.

Для приложения, которое не удалось переустановить автоматически:

1. Нажмите **«Открыть в Store»** или **«Как вернуть»**.
2. Установите приложение из официального источника.
3. Вернитесь в Corelight и нажмите **«Откатить»** или **«Проверить возврат»**.

Запись исчезнет после проверки восстановленной установки. Store может установить другую версию приложения. Для восстановления локальных данных и настроек нужна их отдельная копия.

Для **Dev Home** доступны архивные выпуски Microsoft: поддержка приложения прекращена, а версия из архива может отличаться от удалённой.

Кнопка **«Восстановление системы»** открывает штатное средство Windows для работы с ранее созданными точками.

## Доступность приложений в России

Если WinGet не смог вернуть приложение, попробуйте установить его со страницы в Microsoft Store. Доступность установки может различаться.

Под известными проблемными приложениями есть пояснения. **VPN не гарантирует установку:** учитывается также регион Windows и магазина. Corelight не переключает регион или VPN автоматически.

Автоматический возврат AppX зависит от доступности приложения в Microsoft Store. Если Store не предлагает установку, сохраните сообщение об ошибке для диагностики.

## Если что-то не работает

| Ситуация | Что сделать |
| --- | --- |
| Нет прав администратора | Закройте программу и запустите её с нужными правами. |
| Не создана точка восстановления | Прочитайте причину. При необходимости отмените применение и проверьте защиту системы Windows. |
| Применение или откат завершились с ошибкой | Сохраните отчёт. Проверьте оставшиеся пункты истории и попробуйте откат отдельно для нужного пункта. |
| Windows запретила запись настройки | В сообщении указан параметр. Он может быть защищён Windows или политикой организации, даже при запуске от администратора. |
| Приложение не скачивается | Используйте «Открыть в Store» или официальную инструкцию «Как вернуть»; учитывайте региональные ограничения. |
| Состав настройки изменился | Сохраните бэкап и вернитесь к версии Corelight, которой применялся этот пункт. |
| Ошибка после изменения настройки | Откатите соответствующий пункт. Если это не помогает, используйте заранее подготовленную резервную копию или точку восстановления Windows. |

Журналы находятся в **%ProgramData%\Corelight\logs**, история исходных настроек — в **%ProgramData%\Corelight\backup.json**, сохранённые установщики OneDrive — в **%ProgramData%\Corelight\installers\OneDrive**.

Журнал за конкретный день называется **log-ГГГГММДД.txt**. Для доступа могут понадобиться права администратора. Сохраняйте **backup.json** и установщики, пока нужен откат. Если бэкап повреждён, Corelight сохранит рядом копию **.corrupt-…** и сообщит об этом.

Если старый каталог Corelight унаследовал стандартные права `ProgramData`, новая версия ограничит запись при первом запуске и сохранит историю и журналы. При ошибке для нестандартных разрешений или перенаправления проверьте указанный путь. Сохраните резервные копии до исправления прав.

При обращении с ошибкой приложите версию Windows, название пункта, итоговый отчёт и журнал. Перед публикацией журнала проверьте его на личные данные.

При подтверждении UAC паролем **другого администратора** настройки текущего пользователя относятся к этому администратору. Запускайте программу с пониманием того, для какой учётной записи выполняются изменения.

## Сборка из исходников

Для сборки нужны:

- **Windows 11 x64** — интерфейс использует WPF и системные API Windows.
- **.NET SDK 10.0** — включает инструменты сборки и среду выполнения.
- **Git**, если скачиваете исходники командой git clone. Можно также скачать ZIP репозитория и распаковать его.
- Интернет для первого восстановления NuGet-пакетов и компонентов автономной сборки.

Установите SDK через PowerShell:

~~~powershell
winget install --id Microsoft.DotNet.SDK.10 --exact --source winget
~~~

Либо скачайте **SDK для Windows x64** с [официальной страницы .NET 10](https://dotnet.microsoft.com/en-us/download/dotnet/10.0). Способы установки описаны в [документации Microsoft](https://learn.microsoft.com/en-us/dotnet/core/install/windows).

После установки заново откройте терминал (при необходимости перезапустите VS Code). Проверьте командой **dotnet --list-sdks**, что присутствует версия **10.0.xxx**. Для клонирования проверьте **git --version**. Visual Studio для сборки командами ниже не требуется.

~~~powershell
git clone https://github.com/Shtarkerr/Corelight.git
cd Corelight
dotnet restore Corelight.slnx
dotnet build Corelight.slnx
dotnet test tests/Corelight.Tests --filter 'Category!=Integration'
dotnet publish src/Corelight.App -c Release -o publish/app
~~~

Готовая сборка с лицензиями появится в **publish/app**. Исходники движка находятся в **src/Corelight.Core**, интерфейса — в **src/Corelight.App**, тестов — в **tests/Corelight.Tests**.

Для запуска используйте **publish/app/Corelight.exe**. В эту сборку уже включён .NET. Сборке Debug нужен **.NET Desktop Runtime 10**, который входит в SDK. Для передачи тестировщикам используйте установщик или переносной пакет, описанные ниже.

Интеграционные тесты помечены **Category=Integration**. Они читают состояние Windows и работают со своими временными ключами реестра и файлами. Запуск из терминала администратора может потребоваться для проверки символических ссылок. Реальное применение, удаление приложений и откат проверяются отдельно.

### Сборка установщика и переносного пакета

Для создания комплектов нужны Git, рабочая копия репозитория Corelight и [Inno Setup](https://jrsoftware.org/isdl.php) версии 6.3+ или 7. ZIP распакованных исходников подходит для обычной сборки приложения. Компилятор установщика используют только при подготовке комплектов.

~~~powershell
.\scripts\Build-Packages.ps1
# Если компилятор не найден автоматически:
.\scripts\Build-Packages.ps1 -IsccPath 'C:\путь\к\ISCC.exe'
~~~

Если политика PowerShell запрещает запуск файлов сценариев, выполните из корня репозитория без изменения политики системы:

~~~powershell
& ([scriptblock]::Create([IO.File]::ReadAllText((Join-Path (Get-Location) 'scripts\Build-Packages.ps1')))) -RepositoryRoot (Get-Location).Path -IsccPath 'C:\путь\к\ISCC.exe'
~~~

Сценарий собирает установщик **Corelight-<версия>-Setup-win-x64.exe** и переносной **Corelight-<версия>-Portable-win-x64.exe** со встроенным .NET в **publish\packages\<версия>**. В релиз GitHub прикрепляйте только эти два файла. Контрольные суммы из локального **SHA256SUMS.txt** можно указать в описании релиза. При незакоммиченных изменениях имена пакетов получают суффикс **local**, а версия приложения в журнале — **dirty**. Скрипт ничего не коммитит и не публикует на GitHub.

Исходник установщика находится в **installer\Corelight.iss**. Перед выпуском проверьте установку, ярлыки, обновление поверх прежней версии и удаление с сохранением истории.
