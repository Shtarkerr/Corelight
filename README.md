# Corelight

**Оптимизатор Windows 11 для игрового ПК, рассчитанный на пользователей в России.** Помогает выбрать системные настройки, сократить ненужную фоновую активность, убрать приложения и управлять автозагрузкой.

> **Опубликованная бета 0.1.0-beta.3.** Инструкция описывает текущий код в `main`. Тайм-аут удаления AppX, возврат предустановки, обработка защищённых настроек и обновлённый выбор приложений по умолчанию доступны при [сборке из исходников](#сборка-из-исходников).

## Что умеет программа

- Сканировать систему и показывать рекомендации с описанием последствий.
- Менять настройки приватности, фоновой активности, служб, сети и игровых функций Windows.
- Удалять выбранные предустановленные приложения и отдельно клиент синхронизации OneDrive.
- Включать и отключать программы в автозагрузке.
- Анализировать и очищать временные файлы Windows, выбранные кэши, неработающие ярлыки и корзину.
- Сохранять исходные значения настроек и показывать историю изменений.
- Откатывать доступные изменения, открывать страницы Store и инструкции ручного возврата приложений.

Corelight не разгоняет оборудование, не устанавливает драйверы, не меняет файлы игр, Defender, Secure Boot, TPM или службы античитов. Анимации и прозрачность Windows сохраняются. Центр обновления Windows продолжает работать; можно отключить только раздачу обновлений другим компьютерам.

**Прирост FPS пока не измерен.** Результат зависит от исходного состояния Windows, оборудования и игры. Совместимость со всеми античитами не проверялась.

## Требования и получение программы

- Windows 11, 64-разрядная версия x64.
- Права администратора для запуска.
- Интернет и WinGet (компонент «Установщик приложений») для автоматического возврата приложений из Microsoft Store. Сканирование работает без интернета.

На странице [бета-релиза 0.1.0-beta.3](https://github.com/Shtarkerr/Corelight/releases/tag/v0.1.0-beta.3) выберите файл в разделе **Assets**:

- **Corelight-0.1.0-beta.3-Setup-win-x64.exe** — рекомендуемый установщик. Следуйте подсказкам и запускайте программу через ярлык в меню «Пуск». Ярлык на рабочем столе можно выбрать при установке.
- **Corelight-0.1.0-beta.3-Portable-win-x64.zip** — переносной вариант. Распакуйте архив целиком и запустите **Corelight.exe**; сохраните рядом файлы лицензий.

Устанавливать .NET отдельно не нужно. Выпуск помечен **Pre-release**, контрольные суммы опубликованы в **SHA256SUMS.txt**. Архивы **Source code** содержат исходники для разработчиков; для обычного запуска они не нужны.

Установщик размещает программу и лицензии в Program Files. Установка не применяет оптимизации. **Удаление Corelight не отменяет изменения Windows:** история и резервные копии сохраняются в **%ProgramData%\Corelight**. Для отката переустановите программу и откройте «История и откат».

## Первый запуск

1. Сохраните открытые документы.
2. Запустите **Corelight.exe** и подтвердите запрос прав администратора Windows.
3. Откроется страница **«Главная»** со сведениями о процессоре, видеокарте, памяти и Windows.
4. Нажмите **«Сканировать систему»**.

Сканирование только читает настройки. Если наличие устройства не удалось определить, Corelight учитывает это при выборе рекомендаций.

Сборка пока не имеет цифровой подписи. Перед запуском убедитесь, что файл получен из этого репозитория или собран вами из его исходников.

## Как выбрать рекомендации

На странице **«Результаты сканирования»** прочитайте описание каждого пункта и пояснения под ним.

Рекомендации отсортированы по предполагаемому эффекту: сначала высокий, затем средний, затем остальные. Высокий эффект отмечен фиолетовой плашкой, средний — синей; у низкого отдельной плашки нет. Все пункты остаются доступны для выбора. В «Расширенном» тот же порядок действует внутри каждого раздела, недоступные настройки находятся в конце.

| Отметка | Что означает |
| --- | --- |
| **Безопасно** | Не предполагается отключение заметной пользовательской функции. Всё равно проверьте, нужно ли вам изменение. |
| **Осторожно** | Может отключить используемую функцию или удалить нужное приложение. |
| **Для опытных** | Требуется понимание последствий. По умолчанию такие пункты не выбираются. |
| **Нужна перезагрузка** | Часть результата будет видна после перезагрузки Windows. |
| **Эффект** | Оценка предполагаемого влияния; это не измеренный прирост FPS. |

Безопасные рекомендации отмечены заранее. По выбранным настройкам проекта также отмечены **удаление нового Outlook, удаление Teams и отключение Game DVR**. Они сохраняют отметку «Осторожно». Если пользуетесь почтой, Teams или записью игр через Xbox Game Bar, снимите соответствующую галочку.

**OneDrive, Microsoft News, Microsoft 365 и Solitaire по умолчанию не выбраны.** «Выбрать все» включает и эти пункты, если они есть в списке. Перед применением проверьте, какие приложения вам нужны.

Уже применённые или недоступные настройки не предлагаются повторно. Отсутствие рекомендаций само по себе не означает, что проверены все возможные настройки Windows.

## Как применить изменения

1. Нажмите **«Применить выбранное»**.
2. Проверьте количество пунктов и подтвердите.
3. Corelight попробует создать точку восстановления Windows.
4. Если защита системы не готова, можно включить её и повторить создание точки, продолжить без неё или отменить операцию.
5. Дождитесь отчёта.

Если точка не создана, **«Отмена» позволяет остановиться до применения**. Продолжение без точки не заменяет полноценную резервную копию Windows. Записи Corelight сохраняют исходные параметры, но возврат удалённых приложений зависит от наличия установщиков и доступа к сервисам Microsoft.

В отчёте отдельно показываются успешные изменения, ошибки и результаты, которые пока не подтверждены. При ошибке не повторяйте всю оптимизацию вслепую: прочитайте сообщение и проверьте **«Историю и откат»**.

Corelight ждёт ответа Windows до трёх минут на отдельную операцию удаления пакета AppX. По истечении этого времени программа запросит отмену, остановит оставшуюся очередь и сохранит запись в истории. После тайм-аута или принудительного закрытия программы проверьте, осталось ли приложение, прежде чем повторять операцию.

Если Corelight попросил перезагрузить Windows, сначала сохраните свою работу.

После входа проверьте «Пуск», поиск, «Параметры», интернет и используемые приложения.

Приложения без автоматического возврата, включая Dev Home и старые Советы, требуют ручного выбора. Teams остаётся выбранным по умолчанию, но перед удалением предупреждает о ручной переустановке.

## Раздел «Расширенное»

Здесь настройки собраны по разделам:

- **Приложения** — установленные приложения из каталога и те, которые удалены Corelight.
- **Телеметрия и приватность** — диагностические данные, реклама и связанные фоновые задачи.
- **Интерфейс и фон** — виджеты, рекомендации и фоновая работа приложений.
- **Игровые** — игровой режим, запись игр и другие штатные настройки Windows.
- **Службы** — отключение выбранных необязательных служб.
- **Сеть** — отдельные сетевые настройки; DNS и hosts-файл не меняются.
- **Автозагрузка** — программы, которые запускаются при входе в Windows.

У системной настройки включённый переключатель означает, что оптимизация применена. Выключение запускает возврат сохранённого состояния; если бэкапа нет, используется предусмотренное каталогом значение по умолчанию, которое может отличаться от вашей прежней настройки.

При каждом открытии «Расширенного» Corelight перечитывает состояние системы. Если проверка отдельного пункта не удалась, он помечается как недоступный с указанием причины, а не как отсутствующий. Для служб учитывается также то, остановилась ли служба: если Windows оставила её работающей, программа попросит перезагрузку. При откате по новому снимку программа восстанавливает тип запуска и пытается вернуть прежнее рабочее состояние службы. При ошибке запись остаётся в истории для повторной попытки. Старые снимки содержат только тип запуска.

**Отключение виджетов** доступно в «Расширенном», если установлен их компонент. Если Windows отклоняет запись политики, Corelight помечает пункт недоступным до перезапуска программы. Скрыть кнопку можно в **Параметры → Персонализация → Панель задач → Виджеты**.

У приложения используются кнопки **«Удалить»** и **«Вернуть»**. **AppX-приложения удаляются для всех пользователей ПК и исключаются из подготовки новых профилей.** При автоматическом возврате Store устанавливает приложение для текущего пользователя, а Corelight возвращает сохранённую предустановку для новых профилей. Старые записи истории не содержат сведения о предустановке. Установка в других существующих профилях выполняется отдельно.

Переключатели автозагрузки не удаляют программы. Их изменения не записываются в общую историю оптимизаций: вернуть автозапуск можно тем же переключателем. В списке пока нет автозапуска через задачи планировщика.

## Очистка диска

1. Откройте **«Очистка диска»** в боковом меню и нажмите **«Анализировать»**. На этом этапе файлы сохраняются.
2. Слева выберите категории. Справа проверьте список: можно искать по пути и снимать галочки с отдельных файлов.
3. Нажмите **«Очистить выбранное»** и подтвердите безвозвратное удаление. Кнопка **«Остановить»** завершает обработку после текущего файла; уже удалённые файлы не возвращаются.
4. В результате показаны удалённые данные и пропуски. Причины доступны кнопкой **«Пропуски»**. Для следующей очистки нужен новый анализ; результаты действуют 30 минут.

| Категория | Что очищается | Выбор по умолчанию |
| --- | --- | --- |
| Временные файлы пользователя и Windows | Файлы старше 7 дней в штатных временных папках | Включён |
| Кэш эскизов | Файлы thumbcache старше суток; миниатюры создадутся заново | Выключен |
| Кэш шейдеров DirectX | D3DSCache старше суток; первые запуски игр могут замедлиться | Выключен |
| Отчёты об ошибках и дампы | Диагностические файлы старше 7 дней | Выключен |
| Неработающие ярлыки | Ярлыки старше суток на рабочем столе и в меню «Пуск» с отсутствующей целью на доступном локальном диске | Выключен |
| Корзина | Всё содержимое корзины текущей учётной записи на всех дисках, включая новые элементы | Выключен |

Занятые, изменившиеся после анализа, защищённые и облачные файлы пропускаются. Папки-ссылки и жёсткие ссылки обходятся стороной. Для ярлыков недоступный сетевой или съёмный диск, виртуальная цель и ошибка доступа не означают отсутствующую программу.

**Очистка необратима:** раздел «История и откат» и точка восстановления не возвращают удалённые файлы. Перед очисткой корзины её можно открыть отдельной кнопкой и проверить содержимое. Объём корзины в результате приблизительный; объём остальных удалений считается по успешно удалённым файлам.

Папки «Загрузки» и «Документы», профили браузеров и компоненты обновления Windows сохраняются. При запуске от другого администратора пользовательские папки и корзина относятся к его учётной записи. Обработка папок пользователей других профилей не выполняется.

## OneDrive: что важно до удаления

OneDrive синхронизирует файлы с облаком и может хранить рабочий стол, документы и изображения. Отключение его автозапуска и удаление клиента — разные действия.

Перед удалением:

1. Убедитесь, что не используете синхронизацию на этом ПК.
2. Скачайте нужные облачные файлы на компьютер.
3. Если рабочий стол, документы или изображения перенаправлены в OneDrive, отключите их резервное копирование в настройках OneDrive и проверьте расположение локальных файлов.

Corelight блокирует удаление, если обнаруживает такое перенаправление важных папок. Программа не очищает папку OneDrive и не удаляет ваши документы.

Перед удалением сохраняется штатный установщик с проверкой подписи Microsoft. При возврате он используется для того же варианта установки: текущему пользователю или всем пользователям. Если установщик отсутствует или подпись не проходит проверку, операция останавливается с сообщением.

После возврата могут потребоваться интернет и повторный вход в аккаунт. Сохранённый установщик возвращает клиент OneDrive. Облачные файлы и настройки учётной записи в нём не хранятся.

## Как откатить изменения

Откройте **«История и откат»**. Вверху указаны:

- общее число записей;
- число пунктов, доступных для автоматического отката;
- число пунктов с ручным возвратом.

**Для одного пункта:** нажмите рядом **«Откатить»**.

**Для группы:** нажмите **«Откатить доступное»**, прочитайте список и подтвердите. В окне заранее перечислены пункты, которые не входят в автоматический откат.

Успешно возвращённые пункты исчезают из истории. При ошибке или неподтверждённом результате запись и исходный бэкап сохраняются для повторной попытки. Если программа сообщает, что состав настройки изменился после обновления, используйте предыдущую версию Corelight для её отката и сохраните файл бэкапа.

Для приложения, которое не удалось переустановить автоматически:

1. Нажмите **«Открыть в Store»** или **«Как вернуть»**.
2. Установите приложение из официального источника.
3. Вернитесь в Corelight и нажмите **«Откатить»** или **«Проверить возврат»**.

Программа проверит сохранённое состояние пакетов. Одно открытие страницы магазина не подтверждает восстановление. Store может установить другую версию приложения; прежняя версия, её локальные данные и настройки этим не гарантируются.

Для **Dev Home** доступны архивные выпуски Microsoft: поддержка приложения прекращена, а версия из архива может отличаться от удалённой.

Кнопка **«Восстановление системы»** открывает штатное средство Windows для работы с ранее созданными точками.

## Доступность приложений в России

В проверке на основной Windows WinGet не нашёл Microsoft 365, Microsoft News и Solitaire. Если автоматический возврат не сработал, попробуйте открыть страницу приложения в самом Microsoft Store. Доступность установки может различаться.

Под известными проблемными приложениями есть пояснения. **VPN не гарантирует установку:** учитывается также регион Windows и магазина. Corelight не переключает регион или VPN автоматически.

Если Store не предлагает установку, сохраните сообщение об ошибке. Полное локальное восстановление всех удаляемых приложений ещё не реализовано, поэтому отсутствие приложения в магазине может помешать откату.

## Если что-то не работает

| Ситуация | Что сделать |
| --- | --- |
| Нет прав администратора | Закройте программу и запустите её с нужными правами. |
| Не создана точка восстановления | Прочитайте причину. При необходимости отмените применение и проверьте защиту системы Windows. |
| Применение или откат завершились с ошибкой | Сохраните отчёт. Проверьте оставшиеся пункты истории и попробуйте откат отдельно для нужного пункта. |
| Windows запретила запись настройки | В сообщении указан параметр. Он может быть защищён Windows или политикой организации, даже при запуске от администратора. Для виджетов можно отдельно скрыть кнопку через «Параметры → Персонализация → Панель задач»; это не отключение всей функции. |
| Приложение не скачивается | Используйте «Открыть в Store» или официальную инструкцию «Как вернуть»; учитывайте региональные ограничения. |
| Состав настройки изменился | Сохраните бэкап и вернитесь к версии Corelight, которой применялся этот пункт. |
| Ошибка после изменения настройки | Откатите соответствующий пункт. Если это не помогает, используйте заранее подготовленную резервную копию или точку восстановления Windows. |

Журналы находятся в **%ProgramData%\Corelight\logs**, история исходных настроек — в **%ProgramData%\Corelight\backup.json**, сохранённые установщики OneDrive — в **%ProgramData%\Corelight\installers\OneDrive**.

Путь можно вставить в окно **Win + R**. Журнал за конкретный день называется **log-ГГГГММДД.txt**. Сохраняйте **backup.json** и установщики, пока нужен откат. Если бэкап повреждён, Corelight сохранит рядом копию **.corrupt-…** и сообщит об этом.

При обращении с ошибкой приложите версию Windows, название пункта, итоговый отчёт и журнал. Перед публикацией журнала проверьте его на личные данные.

При подтверждении UAC паролем **другого администратора** настройки текущего пользователя относятся к этому администратору. Запускайте программу с пониманием того, для какой учётной записи выполняются изменения.

## Сборка из исходников

Для сборки нужны:

- **Windows 11 x64** — интерфейс использует WPF и системные API Windows.
- **.NET SDK 10.0** — именно SDK, а не только Runtime. Проект нацелен на .NET 10; .NET 11 отдельно не требуется и как замена SDK 10 не проверен.
- **Git**, если скачиваете исходники командой git clone. Можно также скачать ZIP репозитория и распаковать его.
- Интернет для первого восстановления NuGet-пакетов и компонентов автономной сборки.

Установите SDK через PowerShell:

~~~powershell
winget install --id Microsoft.DotNet.SDK.10 --exact --source winget
~~~

Либо скачайте **SDK для Windows x64** с [официальной страницы .NET 10](https://dotnet.microsoft.com/en-us/download/dotnet/10.0). Способы установки описаны в [документации Microsoft](https://learn.microsoft.com/en-us/dotnet/core/install/windows).

После установки заново откройте терминал (при необходимости перезапустите VS Code). Проверьте командой **dotnet --list-sdks**, что присутствует версия **10.0.xxx**. Для клонирования проверьте **git --version**. Visual Studio для сборки командами ниже не требуется.

~~~powershell
git clone https://github.com/Shtarkerr/Corelight.git
cd Corelight
dotnet restore Corelight.slnx
dotnet build Corelight.slnx
dotnet test tests/Corelight.Tests --filter 'Category!=Integration'
dotnet publish src/Corelight.App -c Release -o publish/app
~~~

Готовая сборка с лицензиями появится в **publish/app**. Исходники движка находятся в **src/Corelight.Core**, интерфейса — в **src/Corelight.App**, тестов — в **tests/Corelight.Tests**.

Для запуска используйте **publish/app/Corelight.exe**. В эту сборку уже включён .NET. Сборке Debug нужен **.NET Desktop Runtime 10**, который входит в SDK. Для передачи тестировщикам используйте установщик или переносной пакет, описанные ниже.

Интеграционные тесты помечены **Category=Integration**. Они читают состояние Windows и работают со своими временными ключами реестра и файлами. Запуск из терминала администратора может потребоваться для проверки символических ссылок. Реальное применение, удаление приложений и откат проверяются отдельно.

### Сборка установщика и переносного пакета

Дополнительно нужен [Inno Setup](https://jrsoftware.org/isdl.php) версии 6.3+ или 7. Компилятор нужен только разработчику; у пользователей устанавливать его не требуется.

~~~powershell
.\scripts\Build-Packages.ps1
# Если компилятор не найден автоматически:
.\scripts\Build-Packages.ps1 -IsccPath 'C:\путь\к\ISCC.exe'
~~~

Если политика PowerShell запрещает запуск файлов сценариев, выполните из корня репозитория без изменения политики системы:

~~~powershell
& ([scriptblock]::Create([IO.File]::ReadAllText((Join-Path (Get-Location) 'scripts\Build-Packages.ps1')))) -RepositoryRoot (Get-Location).Path -IsccPath 'C:\путь\к\ISCC.exe'
~~~

Сценарий собирает свежий self-contained exe, установщик, переносной ZIP с лицензиями и **SHA256SUMS.txt** в **publish\packages\<версия>**. При незакоммиченных изменениях имена пакетов получают суффикс **local**, а версия приложения в журнале — **dirty**. Скрипт ничего не коммитит и не публикует на GitHub.

Исходник установщика находится в **installer\Corelight.iss**. Перед выпуском проверьте установку, ярлыки, обновление поверх прежней версии и удаление с сохранением истории.
